# Task 1 - Tic Tac Toe

## Description
A simple Tic Tac Toe game developed using Python.

## Technology Used
- Python

## How to Run
1. Download or clone this repository.
2. Open the tic_tac_toe.py file.
3. Run the program using Python.

## Features
- Two-player gameplay
- Displays the game board
- Checks for winning combinations
- Detects a draw
